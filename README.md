# Smart AI Tic-Tac-Toe

## Project Description
Smart AI Tic-Tac-Toe is a Python-based game where a human player competes against an AI opponent. The AI uses the Minimax algorithm to make optimal decisions, making it difficult to beat.

## Features
- Human vs AI gameplay
- AI powered by Minimax Algorithm
- Detects Win, Lose, and Draw
- Simple Command Line Interface (CLI)
- Easy to understand and modify

## Technologies Used
- Python 3
- Minimax Algorithm

## Installation

1. Clone the repository:
```bash
git clone https://github.com/shindediksha571/Smart-AI-Tic-Tac-Toe.git
```

2. Open the project folder:
```bash
cd Smart-AI-Tic-Tac-Toe
```

3. Run the project:
```bash
python app.py
```

## How to Play
- You play as **X**.
- The AI plays as **O**.
- Enter a number from **1 to 9** to place your move.
- The AI will automatically make its move.
- The game ends when a player wins or the match is a draw.
